# Derayah Financial – Equity Research

This repository presents my work on Derayah Financial as part of the CFA Institute Research Challenge.

## About the Project

The project involved analyzing Derayah Financial from an equity research perspective, including understanding the company's business model, financial performance, industry environment, and valuation.

## My Focus

My main contribution to the project was Financial Analysis & Valuation, including:

- Financial statement analysis
- Revenue and profitability analysis
- Financial ratios and performance trends
- Valuation analysis
- Scenario analysis
- Identifying key financial drivers and risks

## Tools Used

- Microsoft Excel
- Financial Modeling
- Financial Statement Analysis
- Equity Valuation
- PowerPoint

## Disclaimer

This project was prepared for educational purposes as part of the CFA Institute Research Challenge. The analysis does not represent investment advice.
